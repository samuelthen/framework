# Analysis amendments and researcher decisions

The original `analysis_plan.json` is immutable. Its SHA-256 is recorded by extraction. These amendments describe changes made during the research loop, including exposure to results.

1. **Work-unit audit.** The first operational pass categorized native calls. It showed many mixed Luna calls. Before reporting an intent comparison, extraction was extended to the existing syntax-checked component parser for both models. Pipelines and opaque control blocks remain together. Components are requested candidates, not proven executed actions. Native-call results cannot automatically score each component.
2. **Cost attribution.** The internal equal-allocation field is named `equal_candidate_allocated`; equal weights refer to emitted candidate components. Whole-response associations and mixed-response bounds remain separate. This changes no usage observations.
3. **Independent validation.** The user declined human review and requested executable validation where possible. All five Flipt tasks from the frozen 30-task attempt panel were selected before local test outcomes. No task was selected for a favorable result. Original dataset test patches and fixed selected test names define the scoped checks. Broader semantic contribution judgments remain unvalidated.
4. **Environment repairs.** Initial offline attempts lacked dependencies. Setup resolves reference and baseline package dependencies separately because their Go module versions differ. Setup is not counted as a test success. Go 1.24 is required by the fifth task; its official image is pinned separately. Actual checks disable network. A 3 GB disk reserve limits setup and execution.
5. **Third-model extension.** After observing the two-model accounting results, the pinned Terra run-1 shard was found to be only 21.6 MB. It is added as a declared replication extension on the same tasks, not a new independent task sample or a preregistered primary comparison. The original Gemini–Luna contrast remains primary. The extension is frozen before inspecting its newly extracted component/token metrics.
6. **Scope of contribution.** The new evidence concerns process measurement and accounting. It cannot establish causal over-exploration, safe suppression, or calibrated universal utility without an intervention. No number of iterations substitutes for missing evidence.
