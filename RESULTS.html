Pilot — 50 runs (17 tasks × 3 models), 1,432 operations, every op LLM-labeled

  • Labels: 99.8% valid on first pass or after retries (3 label errors → uncertain). Contribution: 1,357 distinct / 54 non-distinct / 21 uncertain. Relation: 1,216 unmatched / 187 revisits / 17 reproduces / 12 uncertain.
  • Candidate-redundancy rate (reproduces ∧ non-distinct), lo–hi range: Gemini 1.3–2.4%, Luna 1.4%, Terra 0%.
  • Low-contribution tail: mean 0–0.06 ops per run for every model; late non-distinct rate: Gemini 4.1–9.3%, others ≤ 2%. → Test Looper is not supported by this data (the draft pre-registers that outcome).
  • Exact repeats vs. structure (the key comparison): of 21 exact repeats only 4 are candidate-redundant; 13 candidate-redundant ops are not exact repeats. Typical case: test reruns with identical output after an edit are judged distinct (they verify changed code); re-reads of unchanged content via a different command (cat vs sed -n) are judged non-distinct.
  • Return-after-k (Gemini): non-distinct share 16% at k=1 (n=19), 33% at k≥4 (n=75); k=2–3 bins have n ≤ 5, so no reliable trend yet.

Only the fact-defined signatures are evidence here; return_distinct, return_non_distinct and informative_then_redundant are defined by the labels themselves.

Caveats

  • Criterion 4's strongest signature uses the same facts the annotator is shown (same output, object unwritten), so its 100% non-distinct share is partly by construction; human labels are needed to make it evidence.
  • Code state goes "unknown" after inline python - <<PY / python -c scripts (mostly real edits): 24 of 30 test reruns with a prior run could not be confirmed as "unchanged code", so edit_test_identical_test has 0 matches. Needs better write detection (parse write_text/open(...,'w') targets) before M9.
  • Open-SWE-Traces (cross-harness) not included: download too slow from this machine. Open-SWE now also has a v2.0.
  • Annotator: deepseek-v4.1-flash via SoCLaaS x-test-2, reasoning "low" for matched ops, off for unmatched.
